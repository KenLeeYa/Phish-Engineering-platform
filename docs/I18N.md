# I18n Foundation

The admin UI is Chinese-first with `zh-TW` as the default locale and `en-US` as fallback.

## Structure

- Translation files live in `i18n/locales/*.json`.
- Server-rendered templates call `{{t "stable.key"}}`.
- Client-side code can call `window.gophish.t("stable.key")` after `templates/base.html` loads `static/js/dist/app/i18n.min.js`.
- Dynamic backend/API values, campaign statuses, and user-generated content should not be hardcoded into locale files unless they are controlled UI labels.

## Add a Locale

1. Copy `i18n/locales/en-US.json` to `i18n/locales/<locale>.json`.
2. Translate values without changing keys.
3. Add the locale to the loader in `i18n/i18n.go`.
4. Run `go test ./i18n ./controllers`.

Keep keys stable and descriptive. Prefer `domain.label` names such as `nav.campaigns` or `campaign.new`.
