# 中文術語對照

本專案採用繁體中文作為企業資安意識訓練平台的主要介面語言，並保留英文 fallback。

| English | 繁體中文 | 說明 |
| --- | --- | --- |
| Dashboard | 儀表板 | 管理者首頁與摘要資訊。 |
| Campaigns | 演練活動 | 僅限授權訓練，不代表真實攻擊活動。 |
| Email Templates | 郵件模板 | 演練郵件內容範本。 |
| Landing Pages | 教育頁 / 演練頁 | 不應儲存真實密碼或真實憑證。 |
| Sending Profiles | 寄送設定 | SMTP 與寄送治理設定。 |
| Users & Groups | 受測對象與群組 | 受測員工與群組資料。 |
| Results | 演練結果 | 演練互動與學習結果。 |
| Reports | 報表 | 彙整後的治理與成效報告。 |
| Webhooks | Webhooks | 對外事件整合端點。 |
| Account Settings | 帳號設定 | 使用者自身帳號設定。 |

安全邊界：中文化不得改變 campaign sending、tracking、landing-page submission 或 authentication 行為；所有演練必須限於授權訓練情境。
